Project 01 · In Progress
Mobile Application · Service Economy

BookAHand – Home-Service Marketplace Mobile App

BookAHand addresses the everyday friction of sourcing reliable, independent local tradespeople. It provides homeowners and renters with a trusted platform to browse vetted domestic professionals—such as certified electricians, plumbers, and cleaning technicians—with transparent booking steps.

Key Engineering & Design Contributions

  • • UI/UX Design: Conceptualized the user experience flow and interactive component library inside Figma, emphasizing clean visual hierarchy.
  • • Frontend Development: Implemented the mobile client architecture using React Native paired with Tailwind CSS for consistent cross-platform aesthetics.
  • • Authentication Integration: Connected Google Authentication for fast, trusted OAuth single sign-on.
Stack: React Native · Tailwind CSS · Figma · Google Authentication

Redify – Online Book Store

Redify was built to offer a tailored online purchasing environment for literature enthusiasts and academic readers. Built upon WordPress, the platform optimizes book discovery through intuitive genre taxonomies, rich product pages, and reader-first navigation.

Key Implementation Highlights

  • • Catalog & Commerce: Configured detailed author metadata, ISBN categorization, reader reviews, and cart flows.

Stack: WordPress · E-Commerce · PHP · CSS
